# CampusFlowX

CampusFlowX is an offline, menu-driven campus assistant developed as a B.Tech Project-Based Learning (PBL) project. It helps students work with their weekly timetable, find free periods, plan assignments and navigate between campus locations. Teachers can check classroom availability and view room schedules.

The application runs in the terminal and uses local CSV files. It does not require an internet connection, web server, database server or third-party runtime service.

## Main Features

### Student Module

- Set up a student profile using the available course, semester and section information.
- View timetable information.
- Find free periods in the weekly schedule.
- View classroom and campus route information where the supplied data is available.
- Add, view, search, edit and delete assignments.
- Track assignment deadlines, priority, status and completed time.
- Get task-planning recommendations based on available time.

### Teacher Module

- Check whether a classroom is available during a requested time interval.
- View the schedule for a classroom.

### Campus Route Module

- Find routes between locations listed in the campus graph data.
- Uses a shortest-path algorithm to calculate routes and travel distance in minutes.

## Technologies Used

- **C (C11):** Core data-structure and algorithm implementations.
- **C++ (C++17):** Application classes, menus, file handling, validation and business logic.
- **CSV files:** Local storage for timetable, assignment and campus route data.
- **Visual Studio Code:** Recommended editor for viewing and building the source code.
- **MinGW-w64 GCC/G++:** Windows compiler toolchain used by `build.bat`.

## Data Structures and Algorithms

The project includes the following implementations:

- **Linked list:** Used for managing assignment records.
- **Merge sort:** Used for sorting linked-list data.
- **Graph representation:** Used to represent campus locations and connections.
- **Binary min-heap and Dijkstra's algorithm:** Used for shortest-path navigation.
- **Greedy scheduling:** Used to recommend tasks based on priority and time constraints.
- **0/1 Knapsack dynamic programming:** Used for optimized task selection within an available time limit.

## Requirements

To compile the project on Windows, install:

1. **Visual Studio Code** (or another code editor).
2. **MinGW-w64 GCC/G++** with C11 and C++17 support.
3. Add the MinGW-w64 `bin` directory to the Windows `PATH` environment variable.

The `gcc` and `g++` commands must work in the VS Code terminal. The C/C++ extension for VS Code is helpful for editing and IntelliSense, but it does not install the compiler by itself.

## Build and Run on Windows Using VS Code

1. Extract the complete project ZIP file.
2. Open Visual Studio Code.
3. Select **File → Open Folder** and open the `Campus FlowX` project folder (the folder containing `src`, `include` and `data`).
4. Make sure `build.bat` is saved in this project root, alongside the `src`, `include` and `data` folders.
5. Open the VS Code terminal using **Terminal → New Terminal**.
6. Check that the compiler is available:

   ```powershell
   gcc --version
   g++ --version
   ```

7. Run the build script:

   ```powershell
   .\build.bat
   ```

The script compiles every `.c` file with GCC, compiles and links the C++ application with G++, and creates `build\CampusFlowX.exe`. If compilation succeeds, the script launches the application automatically.

You can also double-click `build.bat` in File Explorer to build and launch the application. If Windows reports that `gcc` or `g++` is not recognised, install/configure MinGW-w64 and add its `bin` folder to `PATH`, then reopen VS Code.

## Running the Existing Executable

If you do not want to rebuild, you can run the executable already included in the ZIP:

```powershell
.\build\CampusFlowX.exe
```

Run it from the project root, and keep the `data` folder in its original location. The application looks for the data folder relative to the executable or the current working directory.

## Data Files

The application uses these files from the `data` directory:

- `timetable.csv` — contains course, semester, section, day, subject, start time, end time and classroom information. This is required for the application to start.
- `assignments.csv` — stores assignment details and progress. If it is not present, the application can start with an empty assignment list and create/save assignment data when required.
- `campus_graph.csv` — stores campus locations and connections used by route navigation. If it is missing, route functionality may be unavailable while other modules can still run.

Keep the CSV files in the `data` folder and preserve their column names and structure when editing them.

## Important Notes

- CampusFlowX is an offline academic project; it does not provide live classroom booking or live timetable updates.
- Classroom availability is calculated from the timetable data supplied with the project.
- Route results are limited to locations and connections present in `campus_graph.csv`.
- Assignment data is stored locally in the CSV file; it is not synchronised between computers.
- The current ZIP contains the application source, sample data and an executable. It does not include a separate automated test suite or CMake/Make build configuration.
